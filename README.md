# English Doom 🎮

Gra FPS w stylu Doom do nauki angielskiego! Strzelaj w potwory-słówka i ucz się 50 angielskich słów z kategorii żywności i części ciała.

## 🎯 Demo

Zagraj teraz: [Link do Vercel]

## 🎮 Jak grać

- **Mysz** - Celowanie
- **Lewy przycisk myszy** - Strzał
- **W/S** lub **↑/↓** - Ruch przód/tył
- **A/D** lub **←/→** - Obrót w lewo/prawo

## 📚 Co można się nauczyć

- **25 słów** - Żywność (apple, bread, pizza, etc.)
- **25 słów** - Części ciała (head, eye, hand, etc.)

## 🚀 Uruchomienie lokalnie

Wystarczy otworzyć plik `english-doom.html` w przeglądarce!

- HTML5 Canvas
